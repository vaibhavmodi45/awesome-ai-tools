# Awesome AI Tools [![Awesome](https://awesome.re/badge.svg)](https://awesome.re)

> A large, curated, categorized list of AI tools spanning nearly every major use case — chat assistants, coding, image/video/voice/music generation, writing, document processing, automation, HR, sales, developer infrastructure, and more. Built for developers, creators, freelancers, students, and businesses of any kind, anywhere — this is not scoped to any one country or industry.

Every entry is tagged with how you actually pay for it, so you can filter by budget instead of hype:

| Tag | Meaning |
|---|---|
| 🆓 `Free` | Completely free, no paid tier needed |
| 🟢 `Freemium` | Real, usable free tier, with a paid upgrade for more |
| 🎁 `Trial/Credits` | Free trial period or one-time free credits, then paid |
| 💳 `Paid` | Subscription or paid-only, no meaningful free tier |
| 🔓 `Open Source` | Source code / model weights are open, usually self-hostable for free |

AI tooling moves fast — new entrants monthly, and some tools (Tome's AI slides, OpenAI's original Sora app) disappear just as fast. This list favors tools that are actively maintained and genuinely useful rather than thin wrappers around the same underlying model, and flags anything that's changed direction recently.

## General-Purpose AI Chat Assistants

- [Pi (Inflection AI)](https://pi.ai) 🆓 `Free` - Conversational assistant tuned for supportive, personal-feeling dialogue rather than task completion.

## Local LLMs & Open-Source Model Tooling

- [Ollama](https://ollama.com) 🆓 `Free` 🔓 `Open Source` - The easiest way to run open-weight LLMs (Llama, Mistral, Qwen, DeepSeek, and more) locally with zero API cost.
- [LM Studio](https://lmstudio.ai) 🆓 `Free` - Desktop GUI for discovering, downloading, and running local models, a gentler entry point than raw Ollama.
- [Hugging Face](https://huggingface.co) 🟢 `Freemium` 🔓 `Open Source` - The default hub for open-source models, datasets, and interactive Spaces demos.
- [GPT4All](https://www.nomic.ai/gpt4all) 🆓 `Free` 🔓 `Open Source` - Lightweight desktop app for running local LLMs on consumer hardware, including offline and privacy-first setups.
- [text-generation-webui](https://github.com/oobabooga/text-generation-webui) 🆓 `Free` 🔓 `Open Source` - Popular open-source web UI for running and experimenting with local text-generation models.
- [vLLM](https://github.com/vllm-project/vllm) 🆓 `Free` 🔓 `Open Source` - High-throughput, memory-efficient inference engine for serving open LLMs at scale.
- [llama.cpp](https://github.com/ggml-org/llama.cpp) 🆓 `Free` 🔓 `Open Source` - The foundational C/C++ inference engine behind most local-LLM tools, runs on everything from laptops to Raspberry Pis.
- [Jan](https://jan.ai) 🆓 `Free` 🔓 `Open Source` - Open-source, privacy-focused ChatGPT alternative that runs entirely offline on your own machine.
- [Msty](https://msty.app) 🟢 `Freemium` - Friendly desktop app for running local and cloud models side by side with built-in RAG on your own files.
